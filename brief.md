# Project Brief: GB Fantasy

## Objective
Revamp the existing Group Bets website (https://mark1maria.wixsite.com/groupbets) into a professional Premier League prediction platform.

## Core Concept
- Premier League football prediction game
- 10 matches per gameweek (GW)
- Players submit predictions for each match
- Points-based scoring system
- Leaderboards and tournaments

## Reference Design
Use the same theme/layout style as OLBG Football Betting Tips (https://www.olbg.com/betting-tips/Football/1) for inspiration — professional, dark theme, clean layout.

## Current Site Features (to retain)
- Player registration with username
- Tournament system with entry fees and prize pots
- Live tournament status
- Leaderboard rankings
- Player selections/team picks

## New Features Required
- Premier League fixture display (10 games per GW)
- Prediction submission form (1X2 + score predictions)
- Automated scoring based on actual results
- Gameweek navigation (past/current/upcoming)
- Player statistics and history
- Cash prize distribution display

## Target Look & Feel
- Professional betting tips platform aesthetic
- Dark theme (navy/dark blue base)
- Clean, modern, mobile-responsive
- OLBG-style statistics and layout
