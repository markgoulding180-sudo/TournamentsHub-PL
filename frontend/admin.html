Content Maintenance

Player ID Watchlist

FPL occasionally reassigns a player's numeric ID to a different real player (usually once someone leaves the league). This checks automatically every time player data syncs and logs it here the moment it happens — so it can't silently affect a live tournament without you knowing.

Player Photo Verification

Checks each player's actual photo URL against FPL's CDN (a real request, not just whether a code is stored in the DB) and records the result. Players confirmed to have no working photo are automatically excluded from Bronze/Silver/Gold pack pools going forward — anyone not yet checked still shows up as normal, so this is safe to run at any time. Runs in batches; leave the tab open until it says Done.

Upload Player Photo

Fixes one player at a time. Pick a player below (list comes from the last Photo Verification run), click Search to open Google Images for them in a new tab, download whichever photo you want, then upload it here — it goes straight to storage and is live immediately, no redeploy needed.

TESTING TOOLS

Everything below this line fabricates fake data or bypasses real match results. Genuinely useful for testing right now — but every one of these must be removed before real users are on the platform. See the pre-go-live checklist for the full removal list.

Seed Season Data

Generates a realistic result + full player stats for every real fixture in the gameweek range below — but leaves every match's status as 'upcoming'. Use this once to populate a test season, then use "Mark Games Finished" below to progress through it match by match.

Seed Test Users & Entries

Creates 30 test accounts (shared across all tournament types), then enters them into every live tournament with random-but-valid predictions/picks/squads — the complete test setup from one page. Order: Create Accounts → seed each tournament → Force Close SM Draft last (locks Stock Market squads and opens the market). Enter your own account through each tournament's normal page first if you want to be included.

Mark Games Finished

Select which of this gameweek's matches to mark finished, then click the button. Uses whatever result/stats data already exists for them (e.g. from your own SQL) — doesn't generate anything. Once every match in a gameweek is finished, Stock Market, LMS, and Fantasy all finalize automatically, same as production.

Generate Test Gameweek Data

Fabricates believable match results and player stats for a real gameweek's real fixtures, all in one go — result, goals, assists, clean sheets, cards, minutes, everything consistent with each other. Every tournament type reads the same master data, so this is one action that lets you test everything at once, the same way a real live gameweek would play out.

Stock Market — Full Test Reset

One-click version of the manual SQL reset: wipes every Stock Market table (matchups, history, transactions, entries, stages, tournaments) across the board, creates one fresh tournament at Gameweek 1, and resets the shared master clock. This affects ALL Stock Market tournaments, not just one — same as the manual SQL you've been running.
